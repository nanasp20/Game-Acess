# Game Access - Projeto Integrador SENAC

Bem-vindo ao repositório oficial da **Segunda Etapa** do Projeto Integrador.

### 📝 Sobre a Etapa 6 (Refatoração)
Nesta etapa, o foco foi a limpeza de código e aplicação de **Boas Práticas** e **SOLID**. O objetivo principal foi separar as regras de negócio da interface gráfica (Swing), preparando o sistema para uma futura migração Web.

**Principais mudanças:**
* **Aplicação do SRP (Princípio da Responsabilidade Única):** Separação clara entre Models e DAOs.
* **Padrão DAO:** Criação de classes específicas (`UsuarioDAO`, `JogoDAO`) para acesso ao banco.
* **Code Smells Eliminados:** Remoção de lógica SQL de dentro das classes visuais.

## 🚀 Tecnologias Utilizadas
* **Java 23** (Linguagem Principal)
* **Maven** (Gerenciador de Dependências)
* **MySQL** (Banco de Dados)
* **JDBC** (Conectividade com Banco)
* **NetBeans IDE**
