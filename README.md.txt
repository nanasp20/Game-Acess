# Game Access - Projeto Integrador SENAC

Bem-vindo ao repositório oficial do Projeto Integrador. Este projeto abrange desde a estruturação do Back-end em Java até a interface Front-end Web.

---

## 📝 Etapa 6: Refatoração e Arquitetura
Nesta etapa, o foco foi a limpeza de código e a aplicação de princípios de qualidade de software.
* **Objetivo:** Preparar o código legado para expansão.
* **Ações:** Aplicação de princípios SOLID e remoção de "Code Smells" (códigos ruins ou duplicados).
* **Resultado:** Um código mais limpo e desacoplado da interface gráfica.

## 💾 Etapa 7: Persistência de Dados (DAO)
Nesta etapa, implementamos a conexão robusta com o banco de dados.
* **Objetivo:** Separar a lógica de acesso a dados da lógica de negócio.
* **Ações:**
    * Implementação do padrão **DAO** (Data Access Object).
    * Criação de classes `UsuarioDAO` e `JogoDAO`.
    * Configuração de conexão JDBC com MySQL.
* **Tecnologias:** Java 23, Maven, MySQL.

## 🌐 Etapa 8: Front-End Web
Nesta etapa, desenvolvemos a interface visual do sistema para navegadores.
* **Objetivo:** Criar uma experiência de usuário (UX/UI) moderna e responsiva.
* **Funcionalidades:**
    * Landing Page, Login, Cadastro e Catálogo de Jogos.
    * Validação de formulários com JavaScript.
    * Design responsivo (Mobile First) com CSS Grid e Flexbox.
* **Tecnologias:** HTML5, CSS3, JavaScript.
